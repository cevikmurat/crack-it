How the clues work 💡
🗝️ = a letter that's in the right place  •  🔓 = a correct letter in the wrong place. Every guess must have the same number of letters as the secret word.
How points work ⭐
Crack the word to score: 500 base + speed bonus (the faster, the more — up to +300) + 50 for every guess you didn't need. A 💡 hint costs 150. Scores add up across words, so be fast and sure to top the class!
